# WFC 던전 탈출 게임

Wave Function Collapse(WFC) 오픈소스를 바탕으로 던전을 생성하고, 생성 과정을 관찰한 뒤 출구를 찾아 탈출하는 Unity 2D 프로젝트입니다.

## 1. 기본 설명

실행 파일 : Build/WFCDungeon.exe
소스 코드 : DungeonWave.cs(WFC_project/Assets/WFCPrototype/DungeonWave.cs), DungeonPrototype.cs(WFC_project/Assets/WFCPrototype/DungeonPrototype.cs)

1. Build : 실행 파일이 있습니다.
2. WaveFunctionCollapse-master : 원본 WFC 오픈소스가 있습니다.
3. WFC_project : 던전 생성 프로젝트가 있습니다. Unity 실행파일이 있습니다. Unity Editor에 이 폴더를 추가하여 수정할 수 있습니다.
4.OpenSourceRepoLink.txt : 원본 WFC 오픈소스 링크가 있습니다.
5. README.md : 필수 정보가 포함되어 있습니다.
6. ProjectDemonstrationVideo.mp4 : 프로젝트 시연 영상입니다.

## 2. 실행 방법

※ Unity Hub 없이 프로젝트 게임만 실행시켜보고 싶은 경우

1. Build/WFCDungeon.exe 파일을 실행시킵니다.
2. 게임은 던전 생성 설정 화면에서 시작합니다. 여기서 각종 변수를 설정할 수 있습니다.
3. 던전 생성의 모드도 선택할 수 있습니다. 빠른 생성 모드는 던전의 생성 과정에 대한 자세한 설명없이 던전을 빠르게 생성합니다. 설명 모드는 던전을 생성하는 과정을 천천히 보여주면서 플레이어에게 WFC 알고리즘을 이해시키는 것을 목표로 합니다.
4. 생성을 시작하면 던전을 생성하는 과정을 확인할 수 있습니다. 던전 생성 중 조작에 관한 내용은 아래에 있는 **"4. 게임 방식과 조작법"**를 참고하세요.
5. 던전 생성이 모두 끝나면 가장 길이가 긴 던전 하나만을 남기고 나머지는 제거하며 플레이어는 이 던전을 돌아다니며 출구로 이동합니다.
6. 설정 버튼을 누르면 던전 생성 설정을 변경할 수 있습니다.
7. 종료 버튼을 눌러 게임을 종료할 수 있습니다.

※ Unity Hub로 프로젝트를 직접 수정해보거나 실행시키고 싶은 경우

1. Unity Hub에서 `WFC_project` 폴더를 프로젝트로 추가합니다.
2. **Unity 6000.6.8f1**로 프로젝트를 열고 패키지 설치 및 임포트가 완료될 때까지 기다립니다.
3. `Assets/WFCPrototype/DungeonEscape.unity` 씬을 엽니다.
4. Unity Editor의 **Play** 버튼을 누릅니다. 키보드 조작 시 Game 창에 포커스를 둡니다.
5. 던전의 가로·세로 크기와 타일 등장 빈도, 생성 모드를 설정한 뒤 **시작**을 누릅니다.

가로·세로는 각각 4~20칸입니다. 화면은 FHD(1920×1080)를 기준으로 구성되어 있으며, 작은 화면에서는 자동 축소됩니다.

## 3. WFC 원리와 원본에서 변경한 부분

WFC는 각 칸에 가능한 타일 후보를 두고, 인접 규칙을 만족하도록 후보를 좁혀가는 알고리즘입니다.

1. 각 칸에 배치 가능한 타일 후보를 준비합니다.
2. 미확정 칸 중 **가중치를 반영한 엔트로피가 가장 낮은 칸**을 선택합니다. 비슷한 최솟값 사이에서는 작은 무작위 값을 더해 선택합니다.
3. 선택한 칸의 후보 중 가중치에 따라 타일 하나를 확정합니다.
4. 이웃과 통로가 맞지 않는 후보를 제거하고, 그 영향을 주변 칸으로 전파합니다.
5. 모든 칸이 확정될 때까지 반복합니다. 후보가 하나도 남지 않으면 모순으로 판단합니다.

후보 수가 적으면 일반적으로 선택 가능성이 좁지만, 이 프로젝트의 칸 선택 기준은 후보 수 자체가 아니라 가중치까지 반영한 엔트로피입니다.

원본은 `Program.cs`에서 `Model.Run()`을 호출하고, `SimpleTiledModel` 등의 자식 클래스가 타일과 인접 규칙을 정의합니다. 이 프로젝트는 `Model`을 상속하지 않고 다음 두 스크립트로 역할을 나눴습니다.

| 스크립트 | 역할 및 변경 사항 |
| --- | --- |
| [DungeonWave.cs (DW)](WFC_project/Assets/WFCPrototype/DungeonWave.cs) | WFC 데이터와 알고리즘을 담당합니다. 북·동·남·서를 4비트로 표현한 16종 타일을 사용하고, 맞닿은 두 면의 통로 개방 여부가 일치하도록 규칙을 구성했습니다. 관찰할 칸 선택과 타일 확정을 분리하고, 전파 중 후보 제거를 한 건씩 반환하도록 구현했습니다. 생성 후에는 BFS를 이용해 입구·출구와 플레이할 연결 영역을 선정합니다. |
| [DungeonPrototype.cs (DP)](WFC_project/Assets/WFCPrototype/DungeonPrototype.cs) | Unity에서 설정, 생성 단계, 화면 표시, 입력, 탐험을 관리합니다. `Phase`로 진행 상태를 구분하고 `Advance()`에서 DW 함수를 호출합니다. `Render()`와 `CellView.Draw()`가 설명 문구, 후보 타일, 칸 색상을 표시합니다. |

추가한 주요 기능은 다음과 같습니다.

- **생성 설정:** 맵 크기와 0~4방향 타일의 상대적 등장 빈도를 설정합니다. 입력값은 최종 맵의 비율을 보장하지 않으며, 0인 종류는 후보에서 제외합니다.
- **빠른 생성 모드:** 관찰과 전파 결과를 묶어서 빠르게 보여줍니다.
- **설명 모드:** 관찰할 칸 후보 → 선택된 칸 → 타일 후보 미리보기 → 확정 → 후보 제거를 단계별로 보여줍니다. 파란색은 관찰할 칸 후보, 노란색은 선택된 칸, 초록색은 현재 관찰하여 확정한 칸, 빨간색은 제거되는 후보·경로를 나타냅니다.
- **진행 제어:** 생성 속도 조절, 일시정지, 한 단계 진행, 결과 바로 보기를 제공합니다.
- **플레이 영역 선정:** BFS로 서로 멀리 떨어진 입구·출구를 찾고, 선택된 영역과 연결되지 않은 통로는 빨간색으로 깜빡인 뒤 제거합니다. 선택된 영역 안의 갈림길은 유지합니다. BFS 두 번으로 끝점을 찾는 방식이므로 순환이 있는 던전에서 최장 거리를 항상 보장하지는 않습니다.

## 4. 게임 방식과 조작법

던전 생성이 끝나면 플레이어 **P**가 시작점 **S**에서 출발합니다. 연결된 통로를 따라 출구 **E**에 도착하면 탈출에 성공합니다. 빈칸이나 통로가 연결되지 않은 방향으로는 이동할 수 없습니다.

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 던전 생성 완료 후 플레이어 이동 |
| Space | 생성 중 일시정지 / 재개 |
| N | 생성 과정 한 단계 진행. 길게 누르면 빠르게 반복하며, 입력 후에는 일시정지 상태 유지 |
| F | 생성 중 남은 과정을 생략하고 결과 표시 |
| R | 현재 설정으로 새 던전 생성 |
| 생성 속도 슬라이더 | 생성 속도를 0.5~10배로 조절 |
| 설정 버튼 | 설정 화면으로 돌아가 크기·등장 빈도·모드 변경 |

생성 도중 모순이 생기거나 적절한 탈출 경로를 찾지 못하면 조건에 따라 자동으로 다시 생성합니다. 재시도 후에도 실패하면 설정을 바꾸거나 R키로 다시 시도할 수 있습니다.
